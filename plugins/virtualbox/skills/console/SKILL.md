# Консоль VirtualBox

На хосте Windows из PowerShell запускай Python 3.10+ и `scripts/vm.py` из каталога этого навыка. Нужна установленная Oracle VirtualBox. Если текущая папка отличается, передавай абсолютный путь к скрипту. Целевую ВМ выбирай по точному имени или UUID. Все последующие примеры предполагают, что в `$vmTool` записан полный путь к скрипту, а в `$machineName` — имя выбранной ВМ.

```powershell
python $vmTool list
python $vmTool info $machineName
```

`state=running` означает, что ВМ принимает команды. `additions_level` от 2 означает, что VirtualBox видит системную службу Guest Additions. IP-адрес не требуется. Если машина выключена, согласуй её запуск с задачей пользователя. Скрипт самостоятельно её не запускает.

## Прочитать экран

Хост Windows, PowerShell. Выбери путь для текущего кадра в рабочем каталоге задачи.

```powershell
python $vmTool screen $machineName .\work\screen.png
```

После кода 0 открой полученный PNG инструментом просмотра изображений. Это кадр первого виртуального монитора. Если снимок сделать не удалось, старый файл по этому пути может сохраниться. Не используй его как наблюдение о текущем состоянии.

## Получить текстовый вывод

Для Linux с Bash или Windows с Windows PowerShell и запущенной службой Guest Additions используй `run`. Создай локальный файл UTF-8 с точным текстом команды или многострочного сценария. При создании файла из PowerShell сохраняй литерально символы гостевой оболочки, включая `$` и обратные кавычки. Редактор файлов или одинарная here-string позволяют это сделать.

Пример вызова с хоста Windows в PowerShell. В `$guestUser` укажи известное имя гостевого пользователя. В `$scriptFile` укажи путь к файлу команды.

```powershell
python $vmTool run $machineName --user $guestUser --file $scriptFile
```

При наличии сохранённой записи для пары UUID машины и имени пользователя команда сразу выполняется от этого пользователя. Иначе пароль вводят в системном окне Windows. Сообщи о появившемся окне. Для обычного запуска достаточно `--user`. Используй `--remember`, когда пользователь попросил сохранить доступ на этом ПК, и `--ask` для ввода нового пароля. Сохранение выполняется после успешной команды в Диспетчере учётных данных текущего пользователя Windows. В командную строку и чат пароль не передавай. У каждого запуска отдельная оболочка и свой рабочий каталог. Сценарий для интерактивной программы выполняй в видимой консоли.

Результат — JSON с `stdout`, `stderr` и `vbox_exit` (код VBoxManage, который может отличаться от кода гостевого процесса). При ненулевом коде разберись по обоим потокам. По умолчанию тайм-аут составляет 30 секунд после ввода пароля. Опции `--timeout` и `--shell bash|powershell` меняют его и выбор оболочки. Для внешних программ Windows кодировка вывода зависит от самой программы.

## Ввести команду в видимый терминал

Подходит для уже открытой сессии, RouterOS и машин без Guest Additions. Сначала прочитай свежий кадр. Нужны приглашение ожидаемой оболочки, фокус в терминале и английская раскладка US. Если открыт экран пароля, пользователь входит в ВМ локально. Для операций со своим подтверждением со стороны гостя проверь, в каком поле находится курсор.

Хост Windows, PowerShell. В `$scriptFile` должна быть одна строка печатного ASCII. Конечный перевод строки в файле допустим. Ввод и Enter выполняются отдельно.

```powershell
python $vmTool type $machineName --file $scriptFile
python $vmTool screen $machineName .\work\typed.png
```

Прочитай кадр и сверь строку целиком, особенно кавычки, символы и конец команды. При расхождении или смене фокуса остановись перед Enter. Если ввод прервался по тайм-ауту, перед повтором проверь, какая часть уже попала в терминал. Для длинного или многострочного текста предпочти Guest Control.

После сверки, если задача предполагает выполнение команды, с хоста Windows в PowerShell отправь Enter и прочитай результат.

```powershell
python $vmTool enter $machineName
python $vmTool screen $machineName .\work\result.png
```

Если команда ещё работает, дождись ожидаемого вывода или возврата приглашения и обнови кадр. Успешная отправка нажатия подтверждает доставку клавиши. Об успешном выполнении команды суди по гостевому выводу.

## Обслуживание гостя

Для проверки диска Linux сначала измерь свободное место внутри гостя через `df -Bm /`. Для очистки сопоставь размер каталогов с объектами пакетного менеджера или контейнерной среды. У Docker и containerd могут быть разные наборы образов. Остановленный контейнер может содержать данные лабораторной. Сохраняй пользовательские проекты и тома в соответствии с согласованным объёмом работ. При удалении конкретных образов зафиксируй их имена и digest, при удалении старого ядра проверь активное ядро и план пакетного менеджера. После изменений повтори исходное измерение. Для sudo пользователь вводит пароль непосредственно в терминале ВМ. Разрешения из прошлой очистки относятся только к той операции.
